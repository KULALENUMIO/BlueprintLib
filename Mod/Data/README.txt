Blueprint Lib - data folder

Files the mod creates here (they are yours, never upload them):
  index.json    list of your blueprints, written by Blueprint Lib Manager ("Rescan")
  library.json  your folders / tags / favorites, written by the game and by the manager
  request.json  "place in game" requests from the manager

library.json is also backed up to %APPDATA%\BlueprintLib\ by the manager, because Steam may
replace this folder when the Workshop item is updated. The manager restores it automatically.
