[b]A lift replacement that keeps hundreds of blueprints tidy - folders, tags, favorites - and places them just like the lift.[/b]
[b]何百個ものブループリントを、フォルダ・タグ・お気に入りで整理して、リフトと同じ感覚で設置できるツールです。[/b]

[i]Creative only · Your blueprint files are only read, never changed · English / 日本語 / 한국어 / 中文[/i]
[i]クリエイティブ専用 · ブループリントのファイルは読み取るだけで、変更しません[/i]

[img]https://raw.githubusercontent.com/KULALENUMIO/BlueprintLib/main/docs/images/workshop/banner_first.jpg[/img]
[b]⚠ Run the Manager first - the in-game library stays empty until you do[/b]
[list]
[*]Start [b]Blueprint Lib Manager.bat[/b] (in the mod's folder below) and press [b]Rescan[/b]. Until then the tool only shows "No blueprint list yet".
[*]Do it again whenever you save new blueprints or add / remove mods: [b]Rescan[/b] in the manager, then [b]Reload[/b] in the in-game menu.
[*]Organizing and placing in game work without the manager running. Drag & drop and "Place in game" need it open.
[/list]

[b]⚠ 最初にマネージャーを起動してください（起動するまで、ゲーム内の一覧は空のままです）[/b]
[list]
[*]下の MOD フォルダにある [b]Blueprint Lib Manager.bat[/b] を起動して、[b]「再スキャン」[/b]を押してください。それまでは、ツールを使っても「ブループリント一覧がありません」と表示されるだけです。
[*]ブループリントを新しく保存したときや、MOD を入れ替えたときも、マネージャーで[b]「再スキャン」[/b]→ ゲーム内メニューで[b]「再読込」[/b]を押してください。
[*]ゲーム内での整理と設置は、マネージャーを閉じていてもできます。ドラッグ＆ドロップや「ゲームで設置」は、マネージャーを開いている間だけ使えます。
[/list]

[b]The mod's folder / MOD のフォルダ[/b]
[code]<Steam library>\steamapps\workshop\content\387990\3840235435\[/code]

[b]English[/b]
[list]
[*]Needs [b]Python 3.10 or newer[/b] (python.org - tick "Add python.exe to PATH").
[*]Can't find the folder? In Steam, right-click Scrap Mechanic → Manage → Browse local files, then go up two folders to [b]steamapps[/b].
[*]Why a separate manager? Lua mods can't list folders, so the blueprint list has to be made outside the game.
[/list]

[b]日本語[/b]
[list]
[*][b]Python 3.10 以上[/b]が必要です（python.org から。インストール時に「Add python.exe to PATH」にチェック）。
[*]フォルダが見つからないときは、Steam で Scrap Mechanic を右クリック →「管理」→「ローカルファイルを閲覧」で開いて、2つ上の [b]steamapps[/b] へ進みます。
[*]ゲーム内の Lua からはフォルダの中身を一覧できないため、一覧の作成だけはマネージャーで行います。
[/list]

[img]https://raw.githubusercontent.com/KULALENUMIO/BlueprintLib/main/docs/images/workshop/banner_features.jpg[/img]
[b]English[/b]
[list]
[*][b]Organize[/b] - nested folders, tags, favorites, hidden, recently used
[*][b]Find[/b] - 3 views, search with #tag, sorting
[*][b]Bulk actions[/b] - select many, then move, tag, hide or place one after another
[*][b]Place[/b] - ghost preview like the lift (Q rotate, F height, R physics / fixed)
[*][b]Missing-mod check[/b] - blueprints that need mods not enabled in the world get a ⚠ and can't be placed
[*][b]Browser manager[/b] - drag & drop, required mods with Steam links, "Place in game" button
[*][b]Safe[/b] - edit in game and in the browser at the same time; your library is backed up automatically
[/list]

[b]日本語[/b]
[list]
[*][b]整理[/b] … 階層フォルダ・タグ・お気に入り・非表示・最近使った
[*][b]検索[/b] … 3種類の表示・#タグ検索・並び替え
[*][b]まとめて操作[/b] … 複数選択して、移動・タグ付け・非表示・順に設置
[*][b]設置[/b] … リフトと同じゴースト表示（Q 回転・F 高さ・R 物理あり / 固定）
[*][b]MOD不足チェック[/b] … ワールドで有効でない MOD を使うものには ⚠ が付き、設置できません
[*][b]ブラウザ版マネージャー[/b] … ドラッグ＆ドロップ・必要な MOD と Steam のリンク・「ゲームで設置」ボタン
[*][b]安心[/b] … ゲームとブラウザで同時に編集しても大丈夫。整理情報は自動でバックアップされます
[/list]

[list]
[*]Placing works in single player or as host.
[*]No collision check when placing.

[*]The manager runs only on your PC (127.0.0.1) and stops when you close its tab.
